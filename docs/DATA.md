## The Tampere dataset

Hyvärinen T., Hyysalo A., Kapucu F.E., Aarnos L., Vinogradov A., Eglen S.J.,
Ylä-Outinen L., Narkilahti S. *Comparative microelectrode array data of the
functional development of hPSC-derived and rat neuronal networks.* Scientific
Data 9:118 (2022).

Two pharmacology plates are used:

* **Rat cortical, DIV 22.** Primary rat cortical neurons, 48-well MEA, 16
  electrodes per well. Three 30-minute recordings of the same wells: baseline,
  after compound wash-on, and after TTX.
* **Human, DIV 29.** Human pluripotent-stem-cell-derived neurons, same plate
  format and the same three recordings.

Compounds: CNQX 50 uM, D-AP5 50 uM, GABA 10 uM, gabazine 30 uM, kainic acid
5 uM, and vehicle controls. Seven wells per condition on the rat plate, four on
the human plate.

Three development plates (rat MEA1, human MEA1 and MEA2, DIV 2 to 66) are
downloaded by the fetch script and are available for further work. No result in
this report depends on them.

### Processing

1. `scripts/fetch_tampere.py` downloads the spike tables and metadata and
   writes `data/raw/tampere/SHA256SUMS.json`, a checksum for every file.
   `scripts/verify.py` re-checks them.
2. Electrodes the original authors marked as noisy are dropped, using their own
   `noisy_electrodes_*.csv` files.
3. Analysis windows are three consecutive 60-second blocks starting 300 seconds
   into each recording, the same window on both sides of every pair.
4. Wells with fewer than 50 events or fewer than 3 active electrodes in the
   baseline window are excluded as unreadable, before any model runs. The count
   of exclusions is reported.

Raw voltage traces are available in the dataset and are not downloaded by
default: the published spike times are the input this project uses.

## The domain the twin covers

A simulated culture is admitted to the training bank only when its recording
looks like a living, network-driven preparation and its activity depends on
fast excitatory transmission. The first four conditions are measured on the
recording; the fifth is the property that defines a cortical culture
pharmacologically.

| | |
|---|---|
| firing rate | 0.3 to 40 events per second per electrode |
| active electrodes | at least 60 percent |
| network bursts | at least 1 per minute |
| spikes inside bursts | at least 5 percent |
| firing after an AMPA block | below 35 percent of baseline |

The same criterion applied to the recorded baselines states the twin's domain
of validity rather than hiding it. Recordings outside it are still scored, and
the predictive check is what reports them.

## Simulated data

The training bank is generated by `scripts/make_bank.py` from the simulator in
this repository. It is not distributed with the code; it is rebuilt with one
command, and the simulation is bit-reproducible, so a rebuild from the same
seed produces the same bank.

## Compliance

* No human subject data, no clinical data, no personal information and no
  sensitive personal information is used at any point.
* Both datasets are published research data released under permissive licences
  that allow re-use and redistribution.
* The recordings are of cell cultures. Ethical approval for the original
  animal-derived and stem-cell-derived cultures sits with the publishing
  institution and is documented in their paper.
* No data is redistributed in this repository other than short extracts of the
  CC BY 4.0 dataset in `data/examples/`, each carrying its attribution.
* No output of this project is a medical device, a diagnosis, or advice for use
  on a human.

## External models and services

None. No pretrained model, foundation model, large language model, commercial
API or cloud service is part of the system or was used to produce any number in
the report. Every model in this repository was trained here, from simulations
generated here.
