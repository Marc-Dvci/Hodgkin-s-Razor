## 要解决的问题

神经器官芯片底部的微电极阵列（MEA）能记录培养神经网络的每一次爆发放电，但现有分析止步于描述：放电减少了、爆发变短了、同步性下降了。这类描述无法说明化合物究竟阻断了 AMPA 受体、开放了氯离子通道，还是减慢了突触囊泡的回收，而这几种情况对药物研发的意义截然不同。

## 它做什么

Hodgkin's Razor 把一个生物物理神经网络模型直接拟合到记录数据上。输入同一孔给药前后的两段记录（或两份姊妹培养），针对十种分子机制，分别给出：该机制发生改变的概率、改变幅度（如果确有改变）及其区间。当没有任何模拟与记录相似，或拟合后的数字孪生无法复现记录时，系统会明确说明，不指认任何机制。名字中的"剃刀"指稀疏先验：能解释同一变化的多种机制中，优先选择最少的那一组。

模型完全基于 GPU 模拟数据训练，从未接触过任何化合物标签。

## 结果

所有结果都以同样方式读取的未处理记录作为对照来评分：同一孔给药前的两段记录、均未处理的姊妹培养、溶剂对照孔。一种方法的随机基线，就是在什么都没施加时它自己的命中率。

| 测试（均事先预注册） | 问题 | 结果 |
|---|---|---|
| **慢性 NMDA 阻断**，小鼠海马姊妹培养（Charlesworth 等，2015），第 3 版，盲测 | NMDA 概率能否区分 29 份给药样本与 23 份同基因型未处理样本？阈值 AUROC 0.70 | **0.86**（0.74–0.96）：**达标**。守卫模块判定可解读的样本上为 0.89；已发表的 Doorn 等估计方法 0.49；去掉配对设计 0.66 |
| 同上 | NMDA 是否为排名第一的机制？ | 2/29 对 1/23：**未达标**。没有样本的概率超过 0.5：这是排序，而非判定 |
| 同上，次要指标 | 培养发生代偿后读数是否减弱（与原作者报道一致）？ | 是，早期高于晚期，p = 3e-5 |
| **Dynasore**，人源 iPSC 网络（Doorn 等，2024），第 2 版，盲测 | 至少 10 个孔中 5 个指认出公认机制 | 2/10：**未达标**。机制类别 8/10 正确（p = 0.0016）；守卫模块将其中 7 个孔判为超出模型范围 |
| **实测微通道芯片**（Mateus 等，2024），第 2 版 | 通道统计量能否区分二极管式设计（AUROC ≥ 0.75） | 0.62（0.28–0.88）：未达标，且样本量不足（统计功效 0.48）；数字孪生指出每种设计需要约 20 块芯片 |
| **实测四腔室海马芯片**（Lassers 等，2023），第 4 版 | 轴突放电是否跟随其起源腔室？（孪生预测：至少 0.73） | 0.82，60 组中 49 组：**达标**；两种刺激方案后分别为 0.79 和 0.86 |
| 同上 | 腔室放电时序是否与轴突传导方向基本无关？（孪生预测：Spearman 在 −0.16 至 0.41 之间） | −0.30：**未达标**，方向相反；刺激后落在预测区间内 |

## 快速开始

```bash
pip install -r requirements.txt          # 仅需 CPU
python demo.py                           # 逐孔展示预注册的证据
python demo.py --serve                   # 在 127.0.0.1:8000 启动网页应用
python -m pytest tests/ -q
python scripts/verify.py                 # 核对哈希值、数据校验和、冻结模型及文中写出的每个数字
```

在线演示页面有三个视图：**分析一对记录**（附带每个示例化合物的已知靶点和孪生模型的判断结果，包括判错的情况）、**盲测**（盲测中的每一份样本，可切换方法、对照组和机制，AUROC 在浏览器中实时重算）、**芯片规划**（哪种读出方式能分辨芯片的哪项特性，以及给定芯片数量下的统计功效）。CPU 版 Notebook：`notebooks/hodgkins_razor_demo.ipynb`。

有 CUDA 显卡时，可以从公开数据完整重建整个流程：

```bash
pip install -r requirements-gpu.txt
python scripts/fetch_tampere.py
python scripts/fetch_external.py
python scripts/run_all.py
```

## 工作原理

- **模拟器**：256 个电导型神经元，包含 AMPA、NMDA、GABA-A 突触、紧张性抑制、短时程抑制、异步释放和慢后超极化；每个网络占用一个 CUDA 线程块，结果逐位可复现。
- **记录系统视角**：每种电极阵列的电极布局和检测死区时间，以完全相同的方式作用于模拟数据和实测数据（Axion 48 孔板、MCS 24 孔板、MCS 60 电极阵列）。
- **稀疏先验**：一种化合物只改变一到三种机制；两次记录之间加入在未处理样本上实测的自然漂移。
- **推断**：五个存在性判别头给出每种机制发生改变的概率；条件归一化流给出培养参数及每种改变的幅度。
- **守卫模块**：典型性检验加后验预测检验，任一触发即不指认机制。
- **芯片孪生**：多腔室芯片，腔室之间由微通道相连，可用四种方式读出（腔室电极、2 Hz 钙成像、通道电极、灌流）。它在实验之前回答：哪种读出方式能分辨哪项特性，一个结论需要多少块芯片。

## 验证纪律

共有四份预注册文件，每一份都在读取对应数据之前生成哈希值；读取程序在哈希值匹配之前拒绝返回盲测数据，评估脚本在任何冻结模型被改动时拒绝运行。第 3 版在训练前就提交了"停止规则"：数字孪生必须先在自己的模拟数据上通过测试，才允许冻结。第一次尝试未通过（0.792，阈值 0.80），增加模拟数据后第二次通过（0.810），两次尝试均已公开。

## 局限

- 精确指认单一机制仍是短板。盲测中站得住的是：检测、机制类别，以及单一机制相对未处理培养的排序。
- 在姊妹培养配对上，守卫模块弱于同一孔前后配对。
- 人源培养目前超出模型适用范围。
- 已被完全抑制、不再放电的培养无法解读。
- 后续实验推荐尚未优于固定的后续方案。
- 机制测试基于常规 MEA 培养；芯片孪生在两组实测芯片上接受了检验，一组样本量不足，另一组中两项预测有一项未通过。
