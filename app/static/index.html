Sister cultures from one preparation: one kept on the NMDA blocker APV for days, its sister untreated. The twin reads each pair and gives the probability that each of ten mechanisms moved. Before the experiment: which readout resolves which chip property?

The same simulator runs a two-chamber chip joined by directional microchannels, the geometry of axon-diode neural chips, and reads it four ways. A twin trained per readout on 30,000 simulated chips says how well each property can be recovered from it: the correlation between the true and the inferred value on held-out chips.
